Word Processing Grade 12

Grade 12 reinforces all Grade 10 and 11 Word skills and adds: document metadata, signature lines, content controls (drop-down lists, restricted text, date pickers), advanced mail merge (multiple data sources), tracking changes, bookmarks, cross-references, custom page setup, advanced linking/embedding and professional document production.

GRADE 12 APPROACH

Grade 12 exams include ALL Grade 10 and 11 Word skills, so revise those pages too. New Grade 12 content focuses on problem-solving and integration — applying skills in unfamiliar scenarios.

Document Properties & Status

Every Word file quietly stores a set of facts about itself in the background — who wrote it, when, how many words it has, and a "status" you can set yourself. This hidden information is called metadata (literally "data about data"). Exams often ask you to change the document's Status property to something like Final or Draft — this is just a label, similar to writing "DRAFT" in pencil on a paper document, except it's stored as a property instead of typed into the text.

Step-by-step: Set the document Status
  1. Click File → Info. This screen shows the document's properties on the right.
  2. Look for the Status field (you may need to click Show All Properties at the bottom to see it).
  3. Click in the empty space next to Status and type the required word, e.g. Final.
  4. Click back into the document (or press Esc) to save the change.
WHY THIS MATTERS

Metadata properties (Author, Status, Title, Subject) don't appear on the printed page — they're for organising and searching files, e.g. a school office filtering for all "Final" exam papers before printing. Don't confuse this with typing the word "Final" into the document text — the exam wants the actual property changed.

Signature Lines

A signature line is a placeholder that shows where someone should sign a printed document — like the dotted line and "Sign here" you'd see at the bottom of a letter, except Word generates it for you with a name, title and date automatically lined up underneath.

Step-by-step: Insert a signature line
  1. Click where the signature should appear, then go to Insert→Signature Line (in the Text group) → Microsoft Office Signature Line…
  2. A "Signature Setup" box opens. Fill in the Suggested signer (their name), Suggested signer's title (their job, e.g. Headmaster) and, if asked, their e-mail address.
  3. If the question gives you "Instructions to the signer" text, type it into that box exactly as given.
  4. Tick or untick Show sign date in signature line depending on what's required.
  5. Click OK. A signature box appears in your document with an X, the name and title printed underneath.

Sometimes a document needs to behave a bit like an app — restricting what someone can type, or giving them a list to choose from instead of free typing. Word calls these content controls, and you insert them from the Developer tab. (If you don't see Developer in the ribbon: File → Options → Customize Ribbon → tick Developer in the right-hand list.)

Hyperlinks

  • Link to a website: Ctrl+K → Existing File or Web Page → type URL
  • Link to another file: Ctrl+K → Existing File or Web Page → browse to file
  • Link to email address: Ctrl+K → Email Address

Spreadsheets Grade 12

Grade 12 adds complex functions (Nested IF, AND/OR, VLOOKUP/HLOOKUP, COUNTIFS/SUMIFS, text functions, date/time functions), freezing multiple rows/columns, custom conditional formatting rules, the Subtotal tool, and advanced charts including stacked graphs and trendlines.

Complex Functions

Nested IF

A plain IF can only sort data into two outcomes — true or false. But what if there are three or more possible results, like turning a mark into "Distinction", "Merit", "Pass" or "Fail"? You solve this by putting a second IF function inside the "false" part of the first one, like a chain of yes/no questions: "Is it 80+? If not, is it 60+? If not, is it 50+? If not, it must be a Fail." That's a nested IF.

Nested IF — Grade classification
=IF(B2>=80, "Distinction",
  IF(B2>=60, "Merit",
    IF(B2>=50, "Pass",
      "Fail")))
COUNTING BRACKETS

Each IF needs a closing bracket. With 3 nested IFs, you need 3 closing brackets ))) at the end. Count: one ) for each IF opened.

AND / OR Functions

AND and OR
<-- AND: all conditions must be TRUE -->
=IF(AND(B2>=50, C2>=50), "Pass", "Fail")

<-- OR: at least one condition must be TRUE -->
=IF(OR(B2>=80, C2>=80), "Has Distinction", "No Distinction")

<-- Combined AND + OR -->
=IF(AND(A2="Active", OR(B2>100, C2>100)), "Yes", "No")

LOOKUP Functions

Imagine a school office with a printed list: ID number on the left, learner's surname on the right. If you know someone's ID and want their surname, you'd run your finger down the ID column until you find a match, then read across to the surname column. VLOOKUP does exactly that — it searches down the first column of a table for a value, then "reads across" to grab a value from another column in the same row.

VLOOKUP — looks up values in a vertical table
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])

Example: Look up student ID in B2, find their mark in column 3 of the lookup table
=VLOOKUP(B2, $E$2:$G$20, 3, FALSE)

Arguments:
  lookup_value = the value to search for (B2)
  table_array  = the range to search in ($E$2:$G$20) — always ABSOLUTE!
  col_index    = which column in the table to return (3 = 3rd column)
  range_lookup = FALSE = exact match; TRUE = approximate match

Error: if not found, returns #N/A
HLOOKUP — looks up values in a horizontal table
=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])

Same as VLOOKUP but searches across rows instead of down columns
Step-by-step: Build a VLOOKUP to find a learner's mark
  1. Click the empty cell where you want the answer to appear.
  2. Type =VLOOKUP( to start the function.
  3. Lookup value: click the cell that holds the thing you are searching for (e.g. the learner ID in B2), then type a comma ,
  4. Table array: highlight the whole lookup table (all columns), then press F4 once. This adds dollar signs (e.g. $E$2:$G$20) so the table will not shift when you copy the formula. Type a comma ,
  5. Column number: count which column of that table holds the answer, counting from the LEFT starting at 1. Type that number (e.g. 3 for the 3rd column), then a comma ,
  6. Exact match: type FALSE (this means "only give me an exact match").
  7. Type the closing bracket ) and press Enter. Final formula: =VLOOKUP(B2,$E$2:$G$20,3,FALSE)
EXAM TIP — VLOOKUP

Most common VLOOKUP mistakes: (1) not using absolute reference for table_array ($E$2:$G$20) — it shifts when copied; (2) wrong col_index number — count from the LEFT of the table_array, not from column A; (3) using TRUE instead of FALSE for exact match — always use FALSE in CAT unless told otherwise.

COUNTIFS and SUMIFS

These extend COUNTIF/SUMIF to support multiple criteria:

COUNTIFS and SUMIFS
COUNTIFS: count cells meeting MULTIPLE conditions
=COUNTIFS(A2:A20, "Male", B2:B20, ">=50")
<-- counts rows where A = "Male" AND B >= 50

SUMIFS: sum values meeting MULTIPLE conditions
=SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2)
=SUMIFS(C2:C20, A2:A20, "Cape Town", B2:B20, ">100")
<-- sums C where A = "Cape Town" AND B > 100

ROUNDUP and ROUNDDOWN

ROUNDUP / ROUNDDOWN
=ROUNDUP(A1, 0)    <-- always rounds UP to nearest integer (3.1 → 4)
=ROUNDDOWN(A1, 0) <-- always rounds DOWN to nearest integer (3.9 → 3)
=ROUND(A1, 0)      <-- rounds to nearest (3.5 → 4; 3.4 → 3)

Combining Text Functions

LEFT, RIGHT and MID become far more useful once you combine two of them to build a brand-new code out of pieces of other data — for example, a "family code" made from the first 3 letters of a surname plus the last 3 characters of an admission number.

Building a combined code
Surname in A2 = "Adams", Admission number in B2 = "SC2024112"
=LEFT(A2,3) & RIGHT(B2,3)
<-- LEFT(A2,3) grabs "Ada", RIGHT(B2,3) grabs "112", the & glues them together → "Ada112"
READ THE INSTRUCTION IN ORDER

Build these formulas piece by piece exactly in the order the question describes ("first 3 letters of surname, combined with the last 3 characters of admission number") — write down what each piece should produce before joining them with &, so you can spot which half is wrong if the result looks off.

Freezing Multiple Rows or Columns

Freeze Panes keeps certain rows or columns locked in place on screen while you scroll through a large sheet — like keeping the column headings of a printed table visible at the top of every page. Freezing more than one row works the same way as freezing one, you just need to click in the right place first.

Step-by-step: Freeze the top 3 rows
  1. Click on cell A4 — i.e. the cell in column A of the row directly below the rows you want frozen. (To freeze rows 1–3, you click into row 4.)
  2. Go to View→Freeze Panes→Freeze Panes.
  3. Rows 1–3 now stay visible at the top no matter how far down you scroll. A thin grey line marks the frozen boundary.

The same idea works for columns: click in the first cell of the column you want unfrozen (e.g. C1, to freeze columns A and B), then use the same Freeze Panes command.

Conditional Formatting with Custom Rules

Conditional formatting changes how a cell looks automatically, based on what's inside it — so instead of scanning a long column by eye, the spreadsheet highlights the values that matter for you. A common exam task: make every cell containing a specific word (e.g. "No") stand out in bold red.

Step-by-step: Highlight cells containing specific text
  1. Select the range of cells to check (e.g. D2:D20).
  2. Go to Home→Conditional Formatting→Highlight Cells Rules→Equal To… (or Text that Contains… if it isn't an exact match).
  3. Type the word to match, e.g. No.
  4. Click the format dropdown and choose Custom Format… to set both a font style (Bold) and a fill colour (red), then click OK twice.
EXAM TIP — Conditional Formatting vs typing the format by hand

Never select the matching cells manually and apply bold/colour yourself — markers check that the rule is still attached to the cell. If new data is typed in later and it also says "No", it must automatically turn red too. That only happens with a real conditional formatting rule, not manual formatting.

Subtotal Feature

The Subtotal tool automatically inserts summary rows into a list wherever a chosen column's value changes — for example, a sub-total of marks at the end of every grade, without you manually inserting rows or typing SUM formulas yourself. It only works on a sorted, plain list of data (not inside a table object), so sort by the grouping column first.

  • Data → Subtotal → choose column to group by, function (SUM/AVG/COUNT) and column to calculate
  • Creates outline levels — click 1, 2, 3 buttons to expand/collapse groups
  • Remove: Data → Subtotal → Remove All

Data Validation in Tables

Validation ensures only correct data can be entered. Think of it as a bouncer at the door of each field — the Validation Rule decides what's allowed in, and the Validation Text is the message shown to anyone turned away:

PropertyExampleEffect
Validation Rule>=0 And <=100Marks must be between 0 and 100
Validation Text"Mark must be 0–100"Error message shown when rule is broken
Required = Yes(tick Yes)Field cannot be left empty
Input Mask000-0000000Forces phone number format
EXAM TIP — Rule and Text must match

Always write the Validation Text so it actually describes the Validation Rule. If the rule is >=0 And <=100 but the text says "must be a positive number", a mark of -5 and a mark of 500 would both fail the rule, but the message wouldn't make sense for the second case. Read the rule back to yourself in plain English, then write the text to match it.

Input Masks — Controlling Exactly What Can Be Typed

An input mask is stricter than a validation rule: instead of checking data after it's typed, it controls what you're allowed to type as you type it — similar to how a cellphone number field on a website only lets you type digits, automatically adding the dashes for you. Each position in the mask is built from special characters that mean "a digit must go here", "a letter must go here", and so on.

CharacterMeaning
0 A digit — required (0–9 only, no + or −)
9A digit or blank — optional
L A letter A–Z — required
?A letter A–Z — optional
AA letter or digit — required
aA letter or digit — optional
&Any character — required
>Forces every letter that follows to CAPITALS
<Forces every letter that follows to lowercase
\ Shows the next character literally (e.g. \A always displays the letter "A", it's not a placeholder)
"text"Anything inside quotes is displayed exactly as typed, every time (useful for a fixed prefix)
Worked example: a code that must read "NED26" + 2 capital letters + 3 digits
  1. The fixed part "NED26" never changes, so it's typed literally in quotes: "NED26"
  2. Two required capital letters next: each letter is L , and > beforehand forces capitals, so that's >LL
  3. Three required digits at the end: 000
  4. Joined together, the full input mask is: "NED26">LL000
BUILD IT PIECE BY PIECE

Don't try to write the whole mask in one go. Break the required pattern into chunks exactly as the question lists them, write the mask character for each chunk separately, then join the chunks in order. This is the same "piece by piece" approach used for nested IFs and combined text formulas above.

Lookup Fields — Two Different Sources

A lookup field shows a drop-down list when entering data, but that list can come from two different places — and exams test both, so it's worth knowing which is which.

TypeWhere the list comes fromWhen to use it
Value List You type the exact list of options yourself (e.g. Yes;No;Expires Soon ) when setting up the lookupFixed options that will basically never change, like Yes/No fields
Table/Query lookupThe list pulls live from another table or query (e.g. a Products table)Options that already exist as records elsewhere and might be added to later, like product names or class lists
Step-by-step: Create a typed Value List lookup
  1. Open the table in Design View, click the field, and open the Lookup tab of the Field Properties.
  2. Set Display Control to Combo Box.
  3. Set Row Source Type to Value List.
  4. In Row Source, type each option separated by a semicolon, e.g. Yes;No;Expires Soon.
  5. If users must only pick from this list (no typing their own value), set Limit To List to Yes.

Storing Photos — Attachment Fields

A normal text field can't hold a photo. To let a table store an actual image file against each record (e.g. a passport photo per learner), you need a field with the Attachment data type — Access then keeps the picture inside the database itself.

Step-by-step: Add a field that stores a photo
  1. In Design View, click into a new empty row below the field you want it after, and type the field name (e.g. Photo).
  2. Click into the Data Type column and choose Attachment from the dropdown.
  3. If a description is required, type it in the Description column — this text shows in the status bar when the field is selected in Datasheet View, helping anyone entering data understand what's expected.
  4. In Datasheet View, double-click the small paperclip icon in that field to browse to and attach the actual image file.

EXAM TIP — Designing a Database for a Scenario

You may be asked to design a database from scratch for a given scenario. Steps: (1) Identify the entities (what needs to be stored — e.g. Students, Courses). (2) List the fields for each table. EXAM TIP — Throttling vs Traffic Shaping

Throttling: slows ALL your Internet speed after you reach your data cap. Traffic shaping: selectively slows specific traffic types (e.g. slows YouTube but keeps WhatsApp fast) — used during peak hours to manage congestion. Both are used by ISPs to manage network load.

BITS vs BYTES — a classic catch

Connection speed is in bits per second (Mbps), but file size is in bytes (MB). Since 8 bits = 1 byte, a 80 Mbps line downloads at most about 10 MB per second (80 ÷ 8). Watch the small "b" vs big "B".

Malware — Safeguards

Types of malware (revise from Grade 11): Virus, Worm, Trojan, Ransomware, Spyware, Adware, Keylogger.

Warning Signs of Infection

  • Computer suddenly very slow
  • Frequent crashes or freezing
  • Unexpected pop-up ads
  • Unknown programs running or installed
  • Files missing, renamed or encrypted
  • Browser homepage changed without permission
  • Excessive network/data activity

Term 3

Impact of Social Networking and Technology

Cyber profile / Digital footprint
The accumulated record of your online activity; can affect job prospects and reputation; very difficult to erase
Crowdfunding
Raising money from many people online for a project or cause (e.g. BackaBuddy, GoFundMe)
Fake news / Misinformation
False information spread (deliberately = disinformation; accidentally = misinformation); spreads fast on social media
Information overload
Being overwhelmed by too much information, making it hard to make decisions or focus
Distributed computing power
Combining the processing power of many computers globally to tackle huge problems (research, blockchain)
Cryptocurrency
A digital currency that is almost impossible to trace and does not depend on banks to authorise transactions (Bitcoin, Ethereum); carries a negative connotation due to its link to ransomware
Blockchain
A database that keeps a list (blocks) of ordered records of cryptocurrency transactions

EXAM TIP — Scenario Questions (Question 9 & 10)

Grade 12 Paper 2 ends with integrated scenario questions worth ±25 marks each. These require you to apply knowledge to a real-world situation and make informed recommendations. Structure: identify the issue → explain it → recommend a solution → justify your recommendation. Use specific terminology and link directly to the scenario details. Paragraph answers with reasons earn the most marks.

Test yourself

Try the cybercrime, DDoS & POPIA questions in the Grade 12 Exam Practice.

Common Exam Mistakes

A virus and a worm are the same.
A virus needs a host file and a user to run it; a worm spreads by itself across networks.
A DDoS attack steals your data.
A DDoS attack overwhelms a server so it goes offline — it disrupts access, it doesn't steal data.
A VPN makes your connection less secure.
A VPN encrypts your traffic and makes remote access more secure and private.
