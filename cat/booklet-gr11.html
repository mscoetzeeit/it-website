Grade 11 · Practical (P1)

Word Processing Grade 11

Grade 11 builds on Grade 10 Word skills. New topics include templates, sections, advanced styles, mail merge, references (TOC, footnotes, captions), electronic forms and document themes.

File Management — Extended

Templates

A template is a pre-designed document with built-in formatting and layout. New documents based on the template inherit all its formatting.

  • Use a template: File → New → search for a template or select one from the gallery
  • Create a template: design your document → File → Save As → change file type to Word Template (.dotx)
  • Templates save time for letters, invoices, reports and certificates

Import/Input Data

  • Insert content from other formats: Insert → Object, or copy and paste from Excel/CSV/text files
  • Paste Special (Ctrl+Alt+V): choose HOW to paste — Unformatted Text, Keep Source Formatting, Link, Paste as Picture

Page Layout and Design

Themes

A theme applies a coordinated set of colours, fonts and effects to the entire document: Design tab → Themes.

Cover Page

Insert → Cover Page → choose from built-in designs. The cover page uses content controls for title, subtitle, author, etc.

Advanced Document Layout

Sections and Section Breaks

Sections allow different formatting in different parts of the same document (e.g. different headers, orientation or column layout).

  • Insert a section break: Layout → Breaks → Section Breaks
  • Next Page: new section starts on next page
  • Continuous: new section continues on same page
  • Odd/Even Page: new section on next odd or even page

Headers and Footers — Advanced

In different sections you can have different headers/footers. Fields you can insert:

  • Date: current date (auto-updates)
  • Author: the document creator's name
  • File path and name: shows where the file is saved
  • Document title: the title set in document properties

Advanced Page Numbering

  • Different first page numbering (cover page has no number)
  • Odd/even different page numbers (like a book)
  • Start numbering from a specific number (e.g. start from page 3)
  • Different numbering formats: 1 2 3 / i ii iii / A B C

Columns

  • Layout → Columns → choose number of columns
  • Options: number of columns, spacing between columns, line between columns
  • Column break: forces text to start in the next column (Layout → Breaks → Column)

Paragraph Formatting — Advanced

Customise Bullets and Numbering

  • Click dropdown on Bullets/Numbering button → Define New Bullet/Number Format
  • Change bullet symbol (any character from any font), colour and size
  • Outline Numbering / Multi-level Lists: creates numbered lists with sub-levels (1, 1.1, 1.1.1)

Drop Cap

A drop cap is a large capital letter at the start of a paragraph that drops down across several lines — the decorative big letter you see at the start of chapters in magazines and storybooks.

Step-by-step: Add a dropped cap, 3 lines high, 0.5 cm from the text
  1. Click anywhere inside the paragraph you want to start with a drop cap. (You do not need to highlight anything — just click in the paragraph so the cursor is blinking in it.)
  2. At the top of the screen, click the Insert tab.
  3. Look for the section called the Text group (towards the right-hand side of the ribbon).
  4. Click the Drop Cap (its icon is a large letter "A").
  5. A small menu drops down. Click Drop Cap Options… at the bottom (do not just click "Dropped" yet — we want to set the exact size).
  6. A dialog box opens. Under Position, click the picture labelled Dropped.
  7. In the Lines to drop box, delete the number and type 3.
  8. In the Distance from text box, type 0.5 cm.
  9. Click OK. The first letter of the paragraph is now large and drops down 3 lines.

Styles — Advanced

Styles apply consistent formatting and are essential for automatic Table of Contents generation.

  • Apply a style: select text → click style in the Styles gallery (Home tab)
  • Modify a style: right-click style in gallery → Modify → change font, size, colour, etc. All text using that style updates automatically
  • Create a new style: Home → Styles dialog → New Style button → define name, formatting and base

References

Table of Contents (TOC)

A TOC is generated automatically from Heading styles: References → Table of Contents → choose a style. Update it with: References → Update Table.

Footnotes and Endnotes

  • Footnote: reference note at the bottom of the current page
  • Endnote: reference note at the end of the document
  • Insert: References → Insert Footnote / Insert Endnote

Captions

Labels for figures, tables and images: References → Insert Caption. Captions auto-number (Figure 1, Figure 2, etc.) and can generate a List of Figures.

Citations and Bibliography

References → Manage Sources → add your sources → References → Bibliography → generate automatically formatted bibliography (APA, MLA, etc.)

Index

Mark entries (References → Mark Entry) then insert an index (References → Insert Index) at the end of the document.

Electronic Forms (Legacy Tools)

Forms allow users to fill in specific fields without editing the rest of the document.

  • Developer tab (enable in File → Options → Customize Ribbon)
  • Legacy Tools: Text Form Field, Check Box, Drop-Down Form Field
  • Protect the document: Developer → Restrict Editing → allow only form filling

Mail Merge

Mail merge creates personalised copies of a document for multiple recipients (e.g. 30 personalised letters from one template).

Steps (Mailings tab):

  1. Start Mail Merge → Letters (or Labels, Emails, etc.)
  2. Select Recipients → choose data source (Word table, Excel spreadsheet, CSV file, Access database)
  3. Write your document → insert Merge Fields where the personalised data should go (e.g. <<FirstName>>, <<Address>>)
  4. Preview Results → check how each letter looks
  5. Finish & Merge → Edit Individual Documents (creates a new document with all merged letters) OR Print Documents
EXAM TIP — Mail Merge Data Sources

The data source can be: a Word table, an Excel spreadsheet, a CSV file (comma-separated), or an Access database table. In Grade 11, you use Word tables or spreadsheets. In Grade 12, you extend to all sources including email lists.

Spreadsheets Grade 11

Grade 11 extends on all Grade 10 Excel skills. New topics include absolute references, conditional formatting, advanced functions (IF, COUNTIF, SUMIF, ROUND), charts, sheet manipulation and print options.

FORMULA vs FUNCTION — EXAM WARNING

.">A formula is any calculation you write yourself using operators like +, -, * or / — for example =A1*B1 or =(A1+B1)/2. A function is a built-in keyword that Excel recognises — for example =SUM(A1:A10) or =IF(A1>50,"Pass","Fail").

Exam warning: If the question asks for a formula and you type a function like =SUM, you will lose marks — even if the numeric answer is correct. Read the question carefully: the word formula means you must use operators; the word function means you may use a built-in name.

Absolute vs Relative Cell References

TypeExampleBehaviour when copied
Relative=B2*C2Adjusts automatically (B3*C3, B4*C4…)
Absolute=B2*$C$1The $ locks the reference — C1 stays fixed
Mixed=$B2*C$1Locks either the column ($B) or row (C$1) only
WHEN TO USE ABSOLUTE REFERENCES

Use $ when a cell should NOT change when the formula is copied. Common example: a VAT rate or tax percentage stored in a single cell that is referenced by many formulas. Press F4 to toggle between relative, absolute and mixed modes.

Example — calculating price with VAT
VAT rate is stored in cell B1 (e.g. 15%)
Formula in C3 to add VAT:
=B3 * (1 + $B$1)    <-- $B$1 stays fixed when copied down column C

Conditional Formatting

Conditional formatting automatically changes the appearance of cells based on their values — no formula in the cell is changed.

Step-by-step: Colour all marks below 50 in red
  1. Highlight the cells that contain the marks: click the first cell, hold the mouse button and drag over all of them, then let go.
  2. Click the Home→Conditional Formatting button (in the Styles group).
  3. In the menu, point to Highlight Cells Rules, then click Less Than…
  4. A small box appears. In the white box, type 50.
  5. Click the dropdown on the right and choose Light Red Fill with Dark Red Text (or "Custom Format…" to pick your own colour).
  6. Click OK. Every mark below 50 is now shaded red automatically. If you change a mark to 60, the red shading disappears on its own.
  • Home → Conditional Formatting → New Rule
  • Highlight Cells Rules: colour cells greater than, less than, between, equal to a value; cells with specific text
  • Data Bars: fills cell with a bar proportional to its value
  • Colour Scales: gradient of colours (e.g. red→yellow→green for low→high)
  • Manage/delete rules: Home → Conditional Formatting → Manage Rules

Advanced Functions

ROUND, ROUNDUP, ROUNDDOWN

FunctionSyntaxExampleResult
ROUND=ROUND(number, digits)=ROUND(3.567, 2)3.57
ROUNDUP=ROUNDUP(number, digits)=ROUNDUP(3.561, 1)3.6
ROUNDDOWN=ROUNDDOWN(number, digits)=ROUNDDOWN(3.569, 1)3.5
ROUNDING ≠ FORMATTING

Formatting a number to 2 decimal places only changes how it looks — the underlying value stays the same. ROUND actually changes the stored value. An exam may ask you to distinguish between these two methods.

SMALL and LARGE

SMALL and LARGE
=SMALL(B2:B20, 1)   <-- smallest value (same as MIN)
=SMALL(B2:B20, 2)   <-- 2nd smallest value
=LARGE(B2:B20, 1)   <-- largest value (same as MAX)
=LARGE(B2:B20, 3)   <-- 3rd largest value

POWER

POWER
=POWER(A1, 3)   <-- A1 to the power of 3 (A1³); same as =A1^3

IF Function

The IF function returns one value if a condition is TRUE and another if FALSE.

IF syntax
=IF(logical_test, value_if_true, value_if_false)

Examples:
=IF(B2>=50, "Pass", "Fail")
=IF(C3<0, "Error", C3)
=IF(A1="Yes", 10, 0)
Step-by-step: Use IF to show "Pass" or "Fail"
  1. Click the cell where the result should appear (e.g. next to the first mark).
  2. Type =IF( to begin.
  3. The test: click the cell with the mark, then type the condition. For a pass mark of 50, type >=50 then a comma , — so far: =IF(B2>=50,
  4. If true: type what to show when the test passes, in quotes: "Pass" then a comma ,
  5. If false: type what to show otherwise, in quotes: "Fail"
  6. Type the closing bracket ) and press Enter. Final: =IF(B2>=50,"Pass","Fail")
  7. To copy it down for everyone: click the cell again, then drag the little square at its bottom-right corner (the fill handle) down the column.

COUNTIF

COUNTIF — count cells meeting a condition
=COUNTIF(range, criteria)

=COUNTIF(B2:B30, ">=50")     <-- count cells ≥ 50
=COUNTIF(C2:C30, "Pass")      <-- count cells containing "Pass"
=COUNTIF(D2:D30, "<>0")      <-- count cells not equal to 0

SUMIF

SUMIF — add cells meeting a condition
=SUMIF(range, criteria, sum_range)

=SUMIF(A2:A20, "Cape Town", B2:B20)
<-- adds values in B2:B20 where A2:A20 = "Cape Town"

=SUMIF(C2:C20, ">100", D2:D20)
<-- adds D values where C > 100

Circular Reference

A circular reference happens when a formula refers back to its own cell, directly or indirectly — like trying to weigh yourself while standing on the scale you're holding. Excel can't calculate it because the answer depends on itself.

Example circular reference (in cell A1)
=SUM(A1:A5)  <-- A1 is trying to include itself in the sum

Excel shows a warning when this happens and displays 0 in the cell until the formula's range is corrected to exclude its own cell.

#NULL! Errors

ErrorCause
#NULL!A formula uses a space (which means "intersection") between two ranges that don't actually overlap, e.g. =SUM(A1:A5 C1:C5)

EXAM TIP — IF vs COUNTIF vs SUMIF

IF → returns a value based on a condition (one cell at a time).
COUNTIF → counts how many cells in a range meet a condition (returns a number).
SUMIF → adds values in a range that meet a condition (returns a total).

Databases (Access) Grade 11

Microsoft Access is the database application used in CAT. Databases store structured data in tables and allow powerful filtering, querying and reporting. Grade 11 introduces tables, forms, queries and basic reports.

What is a Database?

A database is an organised collection of related data stored in a structured way so it can be efficiently accessed, managed and updated. A DBMS (Database Management System) is the software used to manage databases. Microsoft Access is a desktop DBMS.

Key Terminology

Table
The fundamental storage object — contains data in rows and columns (like a spreadsheet, but structured)
Record
A complete set of data about one item/person — one row in a table
Field
A single category of information — one column in a table (e.g. FirstName, DateOfBirth, Price)
Field name
The label/heading of a column (e.g. "LearnerID", "Mark")
Primary key
A field (or combination) that uniquely identifies each record — no two records can have the same value (e.g. ID number, StudentCode)
Form
A user-friendly interface for entering, viewing and editing records (one record at a time)
Query
A question asked of the database — returns specific records that meet set criteria
Report
A formatted printable summary of data, often grouped and with calculations

Input Masks — Controlling How Data Is Typed

Think about a cellphone number field. Without any guidance, one person might type 0821234567, another 082 123 4567, and another (082) 123-4567 — all the same number, three different formats. An input mask forces everyone to type data the same way by deciding, character by character, what's allowed in each position.

Mask CharacterMeaning
0A digit (0–9) is required
9A digit is optional
LA letter is required
?A letter is optional
>Converts the following characters to UPPERCASE
<Converts the following characters to lowercase
\The next character is shown as-is (a literal symbol, not a rule)
Step-by-step: Add an input mask to a field
  1. Open the table in Design View and click the field that needs the mask.
  2. In the Field Properties panel at the bottom, click into the Input Mask row.
  3. Type the mask using the characters above. For example, 000-000-0000 forces exactly 10 digits with dashes already in place.
  4. Save the table (Ctrl+S) and switch to Datasheet View to test it — try typing in the field and watch how it guides you.
INPUT MASK vs VALIDATION RULE

An input mask controls the shape of what's typed (how many digits, where the dashes go) as you type it. A validation rule checks the value after it's typed (e.g. is the mark between 0 and 100). Exams sometimes test both on the same field — read carefully which one is being asked for.

Creating Tables

Step-by-step: Create a new table in Design View
  1. At the top of the screen, click the Create→Table Design button. A blank grid opens.
  2. In the first row under Field Name, type the name of your first field (for example LearnerID). Field names should have no spaces.
  3. Press Tab to move to the Data Type column. Click the small arrow and choose the correct type (e.g. Short Text, Number, Date/Time).
  4. Repeat for each field, one per row, until all your fields are listed.
  5. Click the row that should be the primary key (e.g. LearnerID), then click the Primary Key button (a small key icon) on the Design tab. A little key appears next to that row.
  6. To set rules for a field, click it, then change its Field Properties in the panel at the bottom of the screen (field size, default value, required, validation rule, etc.).
  7. Press Ctrl + S to save. Type a name for the table (e.g. tblLearners) and click OK.
  8. Switch to Datasheet View (the grid icon, top-left) to start typing in records.

Datasheet View

  • Add/edit/delete records directly in the table grid
  • Sort: click column header → Home → Sort Ascending/Descending
  • Filter: Home → Filter button or right-click a value

Creating Queries

Queries retrieve specific records from a table based on criteria.

Step-by-step: Build a query to find all Grade 11 learners
  1. Click the Create→Query Design button.
  2. A "Add Tables" panel appears on the right. Double-click the table you want (e.g. tblLearners), then close the panel.
  3. The table appears with a list of its fields. Double-click each field you want to see in the result — they drop into the grid at the bottom.
  4. To filter, find the Criteria row in the grid, under the field you want to filter. Under "Grade", type 11.
  5. Click the big red Run button (exclamation mark !) on the Design tab. Access shows only the records that match.
  6. Press Ctrl + S to save, give the query a name (e.g. qryGrade11) and click OK.
REMEMBER: AND vs OR

To require TWO conditions at once (AND), type both in the same Criteria row. To allow EITHER condition (OR), type the second one in the "or" row just below.

Designing a Database for a Specific Purpose

Before opening Access at all, a good database starts on paper: what information needs to be stored, and how is it split into separate, sensible tables? A common mistake is cramming everything into one table — e.g. storing a learner's name AND every subject they take in the same row, which forces you to repeat the learner's name once per subject. Splitting into a Learners table and a Subjects table, linked by a shared LearnerID, avoids that repetition.

One table, one topic
Each table should describe one type of "thing" — Learners, Subjects, Results — not a mix
Avoid repeating data
If you find yourself typing the same name or address over and over, that data belongs in its own table, linked by an ID
Link tables with a common field
Usually the primary key of one table appears in the other as a "foreign key"

Troubleshooting a Database

ProblemLikely cause / fix
Can't type a record into a tableCheck whether a required field was left blank, or whether a validation rule is rejecting the value
Query returns no resultsCheck criteria spelling, check AND/OR rows are placed correctly, check for extra spaces in typed criteria
Report shows "#Error" in a calculationCheck the field name inside the calculation matches the actual field name exactly, including spelling
Can't delete a recordThe record may be linked to data in another table (referential integrity) — delete the related records first
EXAM TIP — Database Terminology

Know the difference: Table (stores data), Form (data entry interface), Query (filters/retrieves data), Report (formatted printed output). A query returns records from tables; a report presents those records nicely. Use Like "S*" for starts with, Like "*son" for ends with, Like "*an*" for contains "an".

HTML Tables

Table structure
<table border="1">
  <tr>                        <!-- Table Row -->
    <th>Name</th>              <!-- Table Header (bold, centred) -->
    <th>Age</th>
    <th>City</th>
  </tr>
  <tr>
    <td>Amahle</td>            <!-- Table Data (regular cell) -->
    <td>17</td>
    <td>Cape Town</td>
  </tr>
  <tr>
    <td>Johan</td>
    <td>18</td>
    <td>Pretoria</td>
  </tr>
</table>
How to think about building a table (type it in this order)
  1. Start with the table "fence": type the opening <table border="1"> and, a few lines below, the closing </table>. Everything else goes between them.
  2. Each ROW is a <tr> … </tr> pair. Add one <tr></tr> for every row you need.
  3. Inside each row, add the CELLS. Use <th> for heading cells (bold, centred) in the first row, and <td> for normal data cells in the other rows.
  4. Type your text between each cell's tags, e.g. <td>Amahle</td>
  5. Save (Ctrl + S) and refresh the browser (F5) to check it. Count your <td> tags — every row should have the same number of cells.
<table>
Creates the entire table
<tr>
Table Row — one horizontal row
<th>
Table Header cell — bold and centred by default
<td>
Table Data cell — regular content cell

Web Usability — Evaluating Websites

A usable website is easy to navigate and use. Evaluate websites against these criteria:

CriterionWhat to look for

ConsistencySame colour scheme, fonts and layout on all pages

Web Usability — Each Criterion in Detail

1. Readability (Leesbaarheid)
Is text easy to read? Use a clear font, appropriate size, and good contrast (e.g. dark text on light background). Poor readability makes a website difficult to use.
2. Navigation (Navigasie)
Is it easy to move through the website? Is there a clear menu? Can you quickly find what you're looking for? Good navigation = better user experience.
3. Consistency (Konsekwentheid)
Does the website use the same style on all pages? Are colours, buttons and layout the same? This helps users learn to use the website faster.
4. Layout (Uitleg)
Is content neatly organised? Is there enough white space? Is important information prominently visible? A neat layout improves focus and understanding.
5. Typography (Tipografie)
Is the font professional and readable? Are different font sizes used correctly (headings vs body text)? Are too many different fonts avoided? Typography affects readability and appearance.

Web Forms (Vorms)

  • Have clear labels for each input field

Artificial Intelligence (AI) — What is AI?

Artificial Intelligence (AI) is computer software designed to perform tasks that normally require human intelligence — such as learning, problem-solving, language processing and pattern recognition. AI tools (such as ChatGPT, Copilot and Gemini) can generate text, code, images and more.

BIG DATA

Big data refers to extremely large datasets that cannot be processed by traditional methods. Characteristics: Volume (huge amount), Velocity (generated very fast), Variety (many types). Databases are essential for storing and querying big data. AI uses big data to identify patterns and make predictions.

Term 3

Role of AI — Ethical Use and Academic Integrity

  • Using AI as a tool to help — not to do all the thinking for you
  • Academic integrity: submitting AI-generated work as your own is plagiarism
  • Always credit AI assistance in your work
  • Verify AI outputs — AI can produce incorrect information (hallucinations)
  • Consider data privacy — do not enter personal/confidential information into AI tools
Term 3

Social Engineering

DEFINITION

Social engineering = manipulating people psychologically to trick them into giving up confidential information or performing actions that compromise security. It exploits human trust rather than technical vulnerabilities.

Types of Social Engineering / Deception Attacks

Phishing
Fake email that appears to be from a trusted source (bank, government) — tricks you into clicking a link or entering personal info on a fake website
Spear phishing
Targeted phishing attack using your personal details to seem more convincing
Pharming
Redirects you from a legitimate website to a fake one even if you type the correct URL (DNS poisoning)
Vishing
Voice phishing — fraudulent phone calls pretending to be banks/tech support
Pretexting
Creating a false scenario ("I'm from IT, I need your password to fix an issue")
Term 3

Accessibility Options for Users with Disabilities

Screen reader
Reads text on the screen aloud — helps blind or visually impaired users (e.g. NVDA, JAWS)
Screen magnifier
Enlarges parts of the screen — useful for users with low vision
Voice recognition
Converts spoken words to text — allows users to control the computer without a keyboard
Sticky Keys
Lets users press shortcut combinations (such as Ctrl+Alt+Del) one key at a time — helps users with motor difficulties
High contrast
Switches colours so text is easier to read — helps users with visual impairments
Alternative input devices
Eye-tracking, head tracking, touchscreen — for users who cannot use a standard keyboard or mouse

Term 4

Malware — Types and Infection Methods

Malware = malicious software designed to damage, disrupt or gain unauthorised access to systems.

TypeWhat it does
VirusAttaches to legitimate files; spreads when files are shared; can corrupt or delete data
WormSelf-replicating; spreads through networks without user action; slows networks
Trojan horseDisguised as legitimate software; once installed, creates a backdoor for attackers
RansomwareEncrypts your files; demands payment (ransom) to unlock them
SpywareSecretly monitors your activity and sends information to the attacker
AdwareDisplays unwanted advertisements; often bundled with free software
KeyloggerRecords every keystroke — used to steal passwords and credit card numbers

Common Infection Methods

  • Email attachments with malicious files
  • Clicking infected links in emails or websites
  • Downloading software from untrustworthy sources
  • Plugging in an infected USB drive
  • Peer-to-peer (P2P) file sharing networks
  • Visiting compromised websites (drive-by download)
Term 4

Protecting Yourself Online

  • Install and keep updated antivirus/anti-malware software
  • Enable multi-step verification on all important accounts
  • Use SSL/HTTPS websites for banking and shopping (look for padlock)
  • Authorise app permissions carefully — only grant what is necessary
  • Back up data regularly (3-2-1 rule: 3 copies, 2 media types, 1 offsite)
  • Do not click unknown links or open unexpected attachments
Term 4

Data Protection and Privacy

THE GIGO PRINCIPLE

GIGO (Garbage In, Garbage Out) — if incorrect data is entered, the output will also be incorrect. The computer processes what it receives — it cannot fix bad input. Consequences: inaccurate results, poor decision-making, financial losses.

AccuracyValidity
DefinitionHow correct the data is compared to realityWhether the data meets the required format and system rules
FocusIs the information true?Does the data fit within the allowed parameters?
ExampleAge = -5 (not true, but technically a number)Age must be a positive number (rule — so -5 is invalid)
Information accuracy
Data should be correct and up to date. Inaccurate data leads to wrong decisions (GIGO principle: Garbage In, Garbage Out)
Data protection
Keeping data safe from loss, theft or corruption; includes backups, access controls, encryption
Verification
Checking that data entered is consistent and correct (e.g. re-enter password to confirm)
Validation
Checking that data entered is within acceptable range/format (e.g. date must be between 1/1/2000 and today)
EXAM TIP — Malware Questions

Common question: "Name and describe ONE type of malware." Know the definition AND what each type does: Virus (spreads via files), Worm (spreads via network), Trojan (disguised), Ransomware (encrypts + demands payment), Spyware (secretly monitors). Also know infection methods and how to protect against them.

Common Exam Mistakes

A virus and a worm are the same.
A virus needs a host file and a user to run it; a worm spreads by itself across networks.
Phishing is a type of virus.
Phishing is social engineering — tricking a person — not malware.
Validation checks that data was typed correctly.
Validation checks data is reasonable/in range; verification checks it was captured correctly.
