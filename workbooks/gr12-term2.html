LEARN IT

Class, object, attribute, method

A class is the blueprint: it describes what every thing of that kind knows and can do. An object (also called an instance) is one real thing built from the blueprint, with its own values. Attributes are the facts an object stores. Methods are the jobs it can do. A good class keeps its attributes private (hidden inside) and offers public methods, so the only way to read or change the data is through a method that can check the request. This idea of hiding the data behind public methods is called encapsulation. Delphi class names begin with T (TTuckItem), attribute names with f (fPrice) and object names with obj (objChips). You have used classes all year: TButton is a class and btnOK is an object.
LEARN IT

The UML class diagram

A programmer designs a class on paper first, using a UML class diagram: a box with three compartments. A minus sign means private and a plus sign means public.
LEARN IT

One class, many objects

The class is written once. Every time the program calls Create, a new object is built from the blueprint and given its own copy of the attributes.

LEARN IT

The declaration: private attributes, public methods

The class goes in its own unit. The interface part lists everything; the implementation part holds the code. Attributes sit under private, and the methods that the outside world may call sit under public. Methods called Get… are accessors: they hand back a private value. Methods called Set… are mutators: they change one. Create is the constructor that builds the object: one that takes values is parameterised, one that takes none is non-parameterised. Because there are two constructors with the same name, each is marked overload. (Delphi writes the empty method bodies for you if you press Ctrl+Shift+C inside the declaration.)
Delphi
unit UTuckItem;

interface

type
  TTuckItem = class
  private
    fName  : string;
    fPrice : Real;
    fStock : Integer;
  public
    constructor Create; overload;
    constructor Create(sName: string; rPrice: Real; iStock: Integer); overload;
    function    GetName : string;
    function    GetPrice : Real;
    function    GetStock : Integer;
    procedure   SetPrice(rNew: Real);
  end;

LEARN IT

Auxiliary methods and calculated answers

An auxiliary method is a small helper that does one job for the other methods. It is normally declared private, because only the class itself needs it, and it usually only works something out: it hands back a result and changes no attribute. Here the helper builds a price as text, so ToString (below) need not repeat the formatting. FloatToStrF(value, ffFixed, digits, decimals) turns a Real into text with a fixed number of decimals. The private helper is added to the declaration under private: function PriceText : string;
Delphi
function TTuckItem.PriceText : string;
begin
  Result := 'R' + FloatToStrF(fPrice, ffFixed, 6, 2);   // 9.5 becomes 'R9,50'
end;
LEARN IT

Methods that check a rule

A mutator does not have to accept every value. It can test first and change the attribute only when the rule is met. Sell is a function that returns True if the sale went ahead and False if it did not. In a Boolean test each comparison is put in its own brackets when joined with and / or. Add to the declaration: procedure Restock(iQty: Integer); function Sell(iQty: Integer) : Boolean; function IsLowStock : Boolean;
Delphi
procedure TTuckItem.SetPrice(rNew: Real);
begin
  if rNew > 0 then
    fPrice := rNew;              // a price of 0 or less is ignored
end;

procedure TTuckItem.Restock(iQty: Integer);
begin
  if iQty > 0 then
    fStock := fStock + iQty;
end;

function TTuckItem.Sell(iQty: Integer) : Boolean;
begin
  if (iQty > 0) and (iQty <= fStock) then
  begin
    fStock := fStock - iQty;
    Result := True;
  end
  else
    Result := False;
end;

function TTuckItem.IsLowStock : Boolean;
begin
  Result := fStock < 5;           // a Boolean method returns the answer to a yes/no question
end;
LEARN IT

ToString

ToString describes the whole object in one string, ready to show in a label or memo. Join the attributes with +. Numbers must be changed to text first: IntToStr for whole numbers and FloatToStrF for decimals (or the helper above). For a line break between facts use #13#10.

function TTuckItem.ToString : string;
begin
  Result := fName + ' - ' + PriceText + ' (' + IntToStr(fStock) + ' in stock)';

LEARN IT

Declare, create, use

Using an object takes three steps. 1. Declare a variable of the class type (put the unit in the uses clause first). 2. Create the object with the constructor: objChips := TTuckItem.Create(...). 3. Use it by writing the object name, a dot and the method: objChips.GetName. The variable is only a name tag; the object is not built until Create runs, and calling a method before that crashes the program with an Access Violation. The constructor is called on the class (TTuckItem.Create), but every other method is called on the object (objChips.Sell).
Delphi
uses
  ..., UTuckItem;

var
  objChips, objJuice : TTuckItem;      // 1. declare

// inside a button click:
objChips := TTuckItem.Create('Chips', 9.5, 24);   // 2. create (parameterised)
objJuice := TTuckItem.Create;                     //    create (non-parameterised)
objJuice.SetPrice(12);                            //    then fill it in
lblName.Caption  := objChips.GetName;             // 3. use
lblStock.Caption := IntToStr(objChips.GetStock);
memOut.Lines.Add(objChips.ToString);

Filling and showing with nested loops

To visit every cell use a loop inside a loop. The outer loop picks the row. For each row the inner loop runs all the way through the columns, so every cell is visited one whole row at a time. To show the grid, build the text for one row in sLine in the inner loop, but add it to the memo in the outer loop, after the inner loop has finished.
Delphi
// fill: ask for every cell
for r := 1 to ITEMS do
  for c := 1 to DAYS do
    arrSales[r, c] := StrToInt(InputBox('Sales', 'Item ' + IntToStr(r) + ', day ' + IntToStr(c), '0'));

// show: one memo line per row
for r := 1 to ITEMS do
begin
  sLine := '';
  for c := 1 to DAYS do
    sLine := sLine + IntToStr(arrSales[r, c]) + '   ';
  memOut.Lines.Add(sLine);
end;
LEARN IT

Row, column and grand totals

LEARN IT

Computer management

Housekeeping is the regular tidying that keeps a computer fast and roomy: Disk Cleanup deletes temporary files, unused programs are uninstalled, rarely used files are archived onto external storage or compressed to take less space, and a magnetic hard drive is defragmented so that the pieces of each file lie next to each other (never an SSD).

Integrity means that data and the file system stay correct and uncorrupted. Chkdsk (Disk Check) finds and repairs damaged areas, S.M.A.R.T. monitoring warns that a drive is about to fail, a UPS stops a power cut from corrupting a file that is being saved, and regular backups make it possible to restore a file that has been damaged.

System protection keeps unwanted people and programs out: antivirus software, a firewall, regular software updates, strong passwords and user accounts with limited rights.

Cloud computing, SaaS and virtualisation

Cloud computing means renting storage, processing power or software over the Internet and paying for what you use, instead of buying and running your own equipment. SaaS (Software as a Service) is the part where the software itself is rented: you use it in a browser with nothing to install, for example Google Docs or Microsoft 365. The advantages are that capacity can grow or shrink when you need it, you pay only for what you use, files can be reached from any device, the provider's experts keep the software updated and backed up, and people can work on one document together. The disadvantages are that nothing works without an Internet connection, an outage at the provider affects every customer, and the business must trust the provider with its data.

Cloud computing has an effect on hardware: because the heavy work happens on the provider's servers, users can work on cheaper, low-specification computers or thin clients, and a business buys fewer servers of its own. It needs a fast, reliable connection.

Virtualisation means running several virtual machines on one physical computer. Each has its own operating system, memory share and software, and is separated from the others. The benefits are fewer physical machines to buy, power and cool, a damaged virtual machine can be restored from a saved copy, and a mistake in one machine does not harm the others.

Artificial intelligence

Artificial intelligence (AI) is software that does things that normally need human intelligence, such as recognising faces, understanding speech, recommending films or spotting card fraud. Uses include virtual assistants, chatbots for customer service, recommendations on streaming services, fraud detection in banks, medical image analysis and self-driving vehicles.

Its advantages are that it works through huge amounts of data faster than a person, never gets tired, makes fewer mistakes in repetitive work and lets difficult jobs be automated. Its limitations are that it understands nothing, it only finds patterns in the data it was given, it needs large amounts of personal data (a privacy risk), it is expensive to build, it can replace people's jobs, and criminals can use it to make fake videos or voices.

Two limits matter most. Bias happens when the training data is unfair, so the AI repeats the unfairness. Accountability is the question of who answers when an AI decision is wrong: an AI cannot be blamed, so the company that built it or the organisation that used it is responsible, which is why important decisions should be open to human review.

Virtual, augmented and mixed reality

Virtual reality (VR) places the user inside a completely computer-made world and shuts out the real one. It needs a headset with a screen for each eye, motion sensors or trackers, controllers or data gloves, headphones, and a powerful processor and graphics card to draw the scene instantly. It is used for training (pilots, surgeons), education, gaming and treating phobias. Its limitations are that the software is built for one purpose, it cannot easily copy a changing real situation, and long use can lead to addiction and social isolation.

Augmented reality (AR) keeps the real world in view and adds digital information to it, for example furniture shown in your room through a phone, or navigation arrows on a windscreen. It needs a camera and sensors to see where things are, a screen or glasses, a battery that lasts, Wi-Fi or Bluetooth, and a fast processor. Its limitations are that drawing realistic graphics at the right size and angle is hard, and a phone has little storage, power and battery for it.

Mixed reality (MR) goes further: the virtual objects are anchored in the real room and react to it, so a virtual ball can bounce off a real table. It needs the sensors of AR and the processing power of VR, so the equipment is costly.

Computer criminals and the crimes they commit

A hacker gains access to a system without permission; white-hat hackers are hired to test security, black-hat hackers are criminals. A cracker breaks the protection on software or encryption in order to use or share it illegally. A cyber gang is an organised group who share the work of large attacks, such as a scam that needs writers of malware, people who steal data and people who sell it.

CrimeWhat it is
Identity theftStealing someone's personal details to pretend to be them, for example to open an account or take a loan in their name.
PhishingFake emails, SMSs or web pages that look genuine and trick the victim into giving away passwords or card details.
RansomwareMalware that locks or encrypts the victim's files and demands payment to unlock them.
BotnetA network of infected computers (zombies) secretly controlled by a criminal, often used to flood a website with traffic (a DDoS attack) or to send spam.

The effects on a person include money stolen, a ruined credit record, shame and stress, and having to prove they are not the criminal. A business can lose money and customers' trust, may be fined for failing to protect personal information (POPIA), and cannot work while its systems are down. Safeguards work best together: antivirus and a firewall keep malware out, encryption makes stolen data useless, strong passwords with two-step verification protect accounts, regular updates close security holes, regular backups allow recovery from ransomware, and training teaches staff to spot phishing, which is usually the way in.
