LEARN IT

Operators and decisions: the rules and the traps

  • / always gives a Real (23 / 4 = 5.75); div and mod work only on whole numbers. Trunc chops the decimals off, Round goes to the nearest whole number.
  • Order of work: brackets, then not, then * / div mod and, then + - or. Put brackets round every comparison: (iAge > 12) and (iAge < 19).
  • Never put a ; before else. Use begin…end when a branch has more than one statement.
  • CASE needs a whole-number or Char selector (not a string or Real). Ranges are written 80..100, and else catches everything left.
  • Text comparisons are case-sensitive ('a' > 'A'): use UpperCase before comparing user input. Pos gives 0 when nothing is found.
Delphi
case iMark of
  80..100 : sSym := 'A';
  60..79  : sSym := 'B';
  else      sSym := 'C';
end;
if (iMark mod 10 = 0) or (iMark = 99) then   // brackets round each test
  sSym := sSym + '*';
LEARN IT

Loops, strings and number algorithms: the patterns

  • FOR when you know how many times; WHILE (test first, may run 0 times) and REPEAT…UNTIL (test last, runs at least once, stops when the test is True) when you do not. Read the next value inside the loop, or it never ends.
  • Total starts at 0, counter starts at 0 and a flag starts True (assume prime) or False (assume not found) before the loop.
  • Digits of a whole number: mod 10 gives the last digit, div 10 removes it.
  • Factors: iNum mod i = 0. A prime has exactly two factors. The GCD is found by repeating remainder until it is 0.
  • Strings start at position 1. Copy(s, start, count) returns text; Delete(s, start, count) and Insert are procedures that change s. Build a new string with s := s + ch.

LEARN IT

Arrays: the patterns to know by heart

  • Total and average: total starts at 0; average = total / count (a Real).
  • Highest or lowest with its place: start with item 1 as the best; store the index (not only the value) when you find a better one.
  • Linear search: a flag and a WHILE loop that stops when found or when the end is reached. It works on any list.
  • Bubble sort: compare neighbours and swap with a temporary variable. Pass i needs only n - i comparisons. With parallel arrays, swap every array or the names and marks drift apart.
  • Binary search: only on a sorted list. Compare the middle item, then move iLow or iHigh past it.

iBest := 1;                          // highest with index
for i := 2 to 8 do
  if arrTimes[i] > arrTimes[iBest] then

Text files, procedures and functions

  • Pass an array by declaring a type first: type TTimes = array[1..8] of Integer;

Recursion: a function that calls itself

Every recursive routine needs a base case (an answer that needs no further call) and a recursive case that calls itself with a smaller problem, moving towards the base case. Without a base case the calls never stop (a stack overflow). To trace it, write down each call until the base case; then fill in the returned values from the bottom upwards. Anything written after the recursive call happens on the way back.
Delphi
function Factorial(n : Integer) : Integer;
begin
  if n <= 1 then
    Result := 1                        // base case
  else
    Result := n * Factorial(n - 1);    // recursive case
end;
// Factorial(4) = 4 * Factorial(3) = 4 * (3 * Factorial(2)) = 4 * 3 * 2 * 1 = 24

SQL: clause order, joins and the traps

The computer works in this order: FROM (join the tables), WHERE (keep records), GROUP BY, HAVING (keep groups), SELECT, ORDER BY.
  • Aggregate functions (COUNT, SUM, AVG, MIN, MAX) never go in WHERE: use HAVING. Every other field in SELECT must be in GROUP BY.
  • To join two tables, name both after FROM and put the join condition first in WHERE (primary key = foreign key); add any filters with AND. Without it every row is paired with every row (a cartesian product).
  • Text in double quotes, dates between # signs as #yyyy/mm/dd#, IS NULL (never = NULL), LIKE with % as the wildcard. AND is worked out before OR: use brackets.
  • UPDATE and DELETE without WHERE change every record.

LEARN IT

Normalisation, anomalies and big data stores

Repeating the same fact in many rows (redundancy) causes three anomalies: insertion (you cannot record one fact without another), deletion (deleting one fact wipes out another) and modification (a change must be made in many rows, and missing one makes the data disagree with itself). Normalisation removes them by splitting a table. 1NF: one value per cell, no repeating columns, and a primary key. 2NF: in 1NF, and every other field depends on the whole composite key (move a field that depends on part of the key to its own table). 3NF: in 2NF, and no non-key field depends on another non-key field (move that pair out).

LEARN IT

Counting like a computer

Place values in binary double each step: 128  64  32  16  8  4  2  1. Binary to decimal: add the place values that have a 1 (00101101 = 32 + 8 + 4 + 1 = 45). Decimal to binary: divide by 2 again and again and read the remainders from the bottom up, or subtract place values from the left. Hexadecimal (base 16) uses 0 to 9 and A (10) to F (15), and one hex digit is exactly 4 bits, so split a byte into two nibbles: 1010 1101 = A D = AD. To convert hex to decimal use 16s: AD = 10×16 + 13 = 173. n bits give 2n patterns.
Text and storage
ASCII7-bit code (128 characters), usually stored in a byte; English letters, digits and symbols. A = 65, a = 97, 0 = 48, space = 32.
UnicodeUses more bits per character (UTF-8, UTF-16, UTF-32) so it can hold every script (isiZulu, Chinese, Arabic) and emoji; the first 128 codes are the same as ASCII.
Units1 byte = 8 bits; 1 KB = 1 024 bytes; 1 MB = 1 024 KB; 1 GB = 1 024 MB; 1 TB = 1 024 GB. Multiply to go down a unit, divide to go up.
LEARN IT

Pictures, files and compression

A true-colour (24-bit) picture needs 3 bytes per pixel, so size in bytes = width × height × 3. Divide by 1 024 for KB and again for MB. A compression ratio of 20:1 means the compressed file is one twentieth of the original; saving (%) = (original − compressed) ÷ original × 100. Lossless compression (ZIP, PNG) lets you rebuild the original exactly, so use it for documents, logos and medical images. Lossy compression (JPEG, MP3, MPEG-4) throws away detail people hardly notice, so the file is much smaller but the original cannot be rebuilt; more compression means lower quality.

LEARN IT

Cybercrime, criminals and the law

Criminals: a black-hat hacker breaks in for harm or gain (a white-hat hacker does it with permission to find weaknesses); a cracker breaks software protection; a script kiddie uses tools made by others; an insider misuses the access he already has. Other cybercrimes: identity theft, online fraud, cyberbullying, piracy, bandwidth theft, piggybacking on someone’s Wi-Fi and cyber-extortion. Effects: a person loses money, privacy and peace of mind; a business loses money, customers’ trust, trade secrets and time while systems are down, and may be fined. South African law: the Cybercrimes Act makes hacking, ransomware, fraud and malicious messages crimes; POPIA says an organisation may collect personal information only for a stated reason and with consent, must keep it accurate and secure, may keep it no longer than needed, and must report a breach; the ECT Act covers electronic transactions.
LEARN IT

Technology and society

Big Data is data too large, too fast or too varied for ordinary tools: volume, velocity, variety. The Internet of Things is physical objects with sensors that send and receive data automatically. 4IR merges the physical, digital and biological worlds (AI, robots, IoT, Big Data): routine jobs may disappear, new ones appear and workers must retrain. AI and machine learning let computers learn from data to decide or predict; the risks are bias in the data, lost jobs and decisions nobody can explain. Virtual reality (VR) puts you inside a computer-made world with a headset; augmented reality (AR) adds computer images to the real world you still see. Cloud computing rents storage and software over the Internet: pay only for what you use, reach your files anywhere, backups and updates handled for you; but you depend on the connection (and data costs and load shedding), your data sits on someone else’s servers and privacy is a worry. A blockchain is a chain of records, each holding the hash of the block before, copied on many computers, so an old record cannot be changed without notice. The digital divide separates people who have devices, data and skills from those who do not (cost, rural areas, skills). Green computing saves energy and cuts e-waste: power-saving settings, switching off, recycling, longer-lasting devices, cloud sharing. Your digital footprint is the trail of data you leave: active (posts, forms) or passive (cookies, location logs).
