An array is a row of numbered boxes

An array is a row of boxes that share one name. Every box holds one value, all of the same data type, and every box has a number called its index. In this course the first index is 1. We write arrPrices[3] for “box 3 of arrPrices”.
arrPrices123456

Because the index can be a variable, a loop can visit every box: arrPrices[i] is box 1, then box 2, then box 3, as i counts. Length(arrPrices) tells you how many boxes there are (here 6). Box 0 and box 7 do not exist: using one is a range-check error and the program crashes.

Binary search (sorted arrays only)

Look at the middle box. If it is the target, you are done. If it is too small, the target can only be to its right, so move iLow up. If it is too big, move iHigh down. Every step throws away half of what is left. Stop when the target is found, or when iLow > iHigh (nothing left to look at). The array must be sorted, otherwise throwing away half is a guess.
Delphi
iLow := 1;
iHigh := 12;                    // number of boxes in use
bFound := False;
while (iLow <= iHigh) and (not bFound) do
begin
  iMid := (iLow + iHigh) div 2;
  if arrNum[iMid] = iTarget then
    bFound := True
  else if arrNum[iMid] < iTarget then
    iLow := iMid + 1             // target is to the right
  else
    iHigh := iMid - 1;           // target is to the left
end;

Two ways to sort: bubble sort and selection sort

Bubble sort repeats the neighbour walk: in each pass it compares box j with box j + 1 and swaps them if they are out of order. After pass 1 the biggest value is at the end, after pass 2 the second biggest is in place, and so on, so the inner loop can stop one box earlier each pass. The swap needs a spare variable, iTemp. For biggest first, change > to <.
Delphi
for i := iCount - 1 downto 1 do         // passes
  for j := 1 to i do                    // compare neighbours
    if arrNum[j] > arrNum[j + 1] then
    begin
      iTemp := arrNum[j];               // swap with a spare
      arrNum[j] := arrNum[j + 1];
      arrNum[j + 1] := iTemp;
    end;
Selection sort selects the smallest value of the whole array and swaps it into box 1, then the smallest of boxes 2 onwards into box 2, and so on. It remembers the position of the smallest so far in iMin and swaps only once per pass.
Delphi
for i := 1 to iCount - 1 do
begin
  iMin := i;                            // smallest so far is box i
  for j := i + 1 to iCount do
    if arrNum[j] < arrNum[iMin] then
      iMin := j;                        // a smaller one: remember WHERE
  if iMin <> i then
  begin
    iTemp := arrNum[i];
    arrNum[i] := arrNum[iMin];
    arrNum[iMin] := iTemp;
  end;
end;

Binary and decimal in code

The doubling trick is a loop over the characters of the string. Ord(c) - Ord('0') turns the character '1' into the number 1. To go the other way, repeat: the remainder after dividing by 2 (mod 2) is the next binary digit from the right, so each new digit is put at the front of the string. Divide the number by 2 (div 2) and repeat until it is 0.
Delphi
// binary string -> decimal
iDec := 0;
for i := 1 to Length(sBin) do
  iDec := iDec * 2 + (Ord(sBin[i]) - Ord('0'));

// decimal -> binary string
sBin := '';
while iNum > 0 do
begin
  sBin := IntToStr(iNum mod 2) + sBin;   // new digit goes in FRONT
  iNum := iNum div 2;
end;

The motherboard and its buses

The motherboard is the main circuit board: everything plugs into it or is built onto it. The CPU sits in its socket. RAM goes into DIMM slots. Extra cards (graphics, sound, network) go into PCI Express (PCIe) slots. Hard drives and SSDs connect to SATA ports. The power connector brings power from the power supply, a small CMOS battery keeps the clock running when the computer is off, and the BIOS/UEFI chip holds the start-up program. A bus is a set of wires carrying signals between parts: the data bus carries the data and instructions, the address bus carries the memory address where the data is found, and the control bus carries signals that coordinate the parts (for example “read” or “write”). A wider data bus moves more bits at once.

6.2The three buses [3]

The bus carries data and instructions between the parts. The bus carries the location in memory that the CPU wants to read or write. The bus carries signals such as “read” and “write” that coordinate the parts.

LEARN IT

BIOS/UEFI and POST

The BIOS (Basic Input/Output System) or its modern replacement UEFI is a small program stored on a chip on the motherboard. It runs the moment you press the power button. First it runs the POST (Power-On Self-Test), which checks that the CPU, RAM, keyboard and drives respond; a fault produces beeps or an error screen. Then it finds the drive that holds the operating system and passes control to the bootloader, which loads the operating system into RAM. Think of a caretaker who switches on the power and checks the water, lights and alarm before the principal takes over: problems must be found before the day starts. Without a working BIOS/UEFI the computer cannot start, even if the hard drive is perfect.

Memory and storage

Cache is a tiny, very fast memory on or beside the CPU that keeps copies of the data and instructions the CPU uses most. L1 is the smallest and fastest (inside each core), L2 is bigger and a little slower, and L3 is the largest of the three and is shared by the cores. The CPU looks in L1, then L2, then L3, then RAM, then storage. Keeping a copy of often-used data in a faster place is called caching; a web browser's cache does it for web pages.

RAM is the computer's working memory: it holds the programs and files in use now, it is read-write and volatile (it loses everything when the power goes off). ROM is read-only memory that keeps its contents without power; it holds permanent start-up instructions such as the BIOS/UEFI. Storage keeps files when the computer is off. A hard disk drive (HDD) stores data magnetically on spinning platters read by a moving head: it is cheap per gigabyte and has a large capacity, but it is slower, noisy and can be damaged if dropped. A solid state drive (SSD) stores data in flash memory chips with no moving parts: it is much faster, silent, uses less power and survives knocks, but costs more per gigabyte.

Operating systems and doing many things at once

An operating system (OS) manages the hardware and runs programs. A stand-alone OS serves one user on one computer (Windows 11 on a laptop). A network OS runs on a server and manages users, files, printers and security for many computers. An embedded OS is built into a device that does one job with very little memory (an ATM, a router, a smart TV). A mobile OS (Android, iOS) suits touchscreens and long battery life.
Multitasking: the OS gives each open program a tiny slice of time in turn, so they appear to run together. Multithreading: one program is split into threads that progress together, so a slow part such as a download does not freeze the rest. Multiprocessing: a computer with more than one CPU core really runs several tasks at the same instant.
LEARN IT

Virtual memory and translators

When RAM is full the OS uses part of the storage drive as extra memory, called virtual memory: parts of programs not needed right now are swapped out to the drive and swapped back later. It lets more programs run, but the drive is far slower than RAM. If the computer spends more time swapping than working, that is thrashing; the cure is to close programs or add RAM.
The CPU only understands machine code. A compiler translates the whole program before it runs and produces an executable file (Delphi does this): errors are reported first and the finished program runs fast. An interpreter translates and runs the program one line at a time (Python, JavaScript): it starts at once but runs slower, and a mistake only shows when that line is reached.

LEARN IT

A star network and its devices

In a star topology every device has its own cable to a central switch. If one cable or computer fails, the rest keep working, and it is easy to add a device or find a fault. But if the switch fails the whole network fails, and it needs more cable. Every device needs a NIC (network interface card) to join the network. The switch joins the devices of the LAN and sends each message only to the device it is meant for. The router joins the LAN to another network such as the internet and directs data using IP addresses. The modem converts between the digital signals of the computers and the signal on the fibre, phone or mobile line to the internet service provider.

Malware and backups

Malware is software designed to cause harm. A virus attaches itself to a file and spreads when the file is opened. A worm spreads across a network by itself. A trojan pretends to be useful software but lets an attacker in. A rootkit hides deep in the OS so that an attacker can control the computer unseen. Ransomware encrypts your files and demands payment. Spyware secretly records what you do; adware shows unwanted adverts. Protection: antivirus, a firewall, updates, strong passwords and care with links and attachments.
A backup is a copy of data kept so that it can be restored. A full backup copies everything (quickest to restore). An incremental backup copies only what changed since the last backup of any kind (quickest to make, slowest to restore). A differential backup copies what changed since the last full backup. Copies can be kept locally (fast, but lost in a fire or theft), off-site or in the cloud. The 3-2-1 rule: 3 copies, on 2 kinds of media, with 1 off-site.
