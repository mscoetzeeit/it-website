LEARN IT

Algorithms and the problem-solving cycle

An algorithm is a clear, step-by-step list of instructions that solves a problem. A recipe is an algorithm. A good algorithm is clear (each step has only one meaning), in the right order, finite (it ends), correct and efficient (no wasted steps).
Programmers follow a cycle: 1 Understand the problem → 2 Plan (IPO table, flowchart, pseudocode) → 3 Write the code → 4 Test (trace table) → 5 Fix the errors and test again.
LEARN IT

LEARN IT

Flowcharts and pseudocode

A flowchart draws an algorithm and arrows show the direction. Pseudocode writes it in plain, structured English. Neither is real Delphi. Here is the same algorithm both ways.
  • Oval: start or end
  • Parallelogram: input or output
  • Rectangle: a process (calculation)
  • Diamond: a yes/no decision
Pseudocode
START
  INPUT fare, people
  SET share TO fare / people
  OUTPUT share
END

Pseudocode rules: key words in CAPITALS, indent inside IF, one action per line, begin with START and end with END.

The operators

Delphi has six arithmetic operators. / always gives a Real, even when the answer looks whole. DIV gives the whole-number part of a division and MOD gives the remainder. Use n MOD 2 = 0 to test for an even number and n MOD 10 to get the last digit. Inc(x) adds 1 to x and Dec(x) subtracts 1.

LEARN IT

Order of operations

Delphi works in this order: 1 brackets ( ), 2 then * / DIV MOD, left to right, 3 then + and -, left to right. Use brackets to make your meaning clear. Example: 7 + 15 MOD 4 * 2. MOD and * come first, from the left: 15 MOD 4 = 3, then 3 * 2 = 6, then 7 + 6 = 13. To average three marks you must write (iMark1 + iMark2 + iMark3) / 3: without the brackets only iMark3 would be divided.

Random, Round and Sqrt

Random(n) gives a whole number from 0 to n-1, so add to shift it: Random(6) + 1 is a die (1 to 6). Call Randomize once when the program starts. Round(x) gives the nearest whole number. A value exactly halfway goes to the even neighbour, so Round(2.5) is 2 but Round(3.5) is 4. Sqrt(x) gives the square root as a Real. It cannot take a negative number.
Delphi
Randomize;                       // once, at the start
iDie := Random(6) + 1;           // 1, 2, 3, 4, 5 or 6
iNear := Round(12.678);          // 13
rRoot := Sqrt(49);               // 7.0 (a Real)
lblSide.Caption := IntToStr(Round(Sqrt(30)));   // 5

LEARN IT

Binary place values

Decimal uses 10 digits and every column is worth 10 times the one on its right. Binary (base 2) uses only 0 and 1 and every column is worth 2 times the one on its right. A bit is one binary digit; a byte is 8 bits.
1286432168421
00101101
Binary to decimal: add the place values where there is a 1. 00101101 = 32 + 8 + 4 + 1 = 45.
Decimal to binary: go from the biggest place value down. Does it fit? Write 1 and subtract; if not, write 0. For 77: 64 fits (13 left); 32 no; 16 no; 8 fits (5 left); 4 fits (1 left); 2 no; 1 fits. So 77 = 01001101.

Hexadecimal

Long binary numbers are hard to read. Hexadecimal (base 16) has 16 digits: 0 to 9 and then A=10, B=11, C=12, D=13, E=14, F=15. One hex digit is exactly 4 bits, so you can convert in groups of four bits. Hex is used for colour codes (#FF0000 is red) and memory addresses.
Binary01011001101011001111
Hex59ACF
Binary to hex: split into groups of 4: 1011 0111 → B and 7 → B7.
Hex to decimal: each column is worth 16 times the one on its right: 2A = 2 × 16 + 10 = 42.
Decimal to hex: divide by 16: 200 ÷ 16 = 12 remainder 8, so 200 = C8.

A computer stores a letter as a number. Measuring storage

A bit is one 0 or 1. A byte is 8 bits and stores one ASCII character. Computers count in powers of two, so each unit below is 1 024 times the one before.
UnitSizeExample

1 kilobyte (KB)1 024 byteshalf a page of text
1 megabyte (MB)1 024 KBa photo, a song
1 gigabyte (GB)1 024 MBa film, a game

To go to a smaller unit multiply by 1 024; to go to a bigger unit divide by 1 024.
