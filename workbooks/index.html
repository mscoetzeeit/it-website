Think & Write Workbooks

Printable, pen-and-paper workbooks, one per term for each grade. No computer needed: you think, learn and prove your skills by writing on the page.

1. Think firstA short activity on paper, before any Delphi. It gets you ready for the big idea.
2. Learn itA clear explanation of the Delphi that goes with it, with a worked example.
3. Prove itTrace tables, predict the output, find the bugs and write code by hand.
4. CheckpointA timed test at the end of the workbook, then a warm-up for next term.

How to print

Use the PDF (or the Print button on the workbook page). Print on A4, double-sided, black and white, at 100% / actual size (do not choose “fit to page”). Each workbook is between 25 and 32 pages, so about 13 to 16 sheets.

Pilot edition — feedback welcome

The Grade 10 workbooks are the first to be published. If you are a teacher using it, please tell Ms Coetzee what worked and what did not: was it the right length and level, were the instructions clear, and was there enough writing space? The same layout will be used for all the other workbooks, so your comments help a lot.

Each workbook follows the Annual Teaching Plan for its term. An answer memo for teachers is available from Ms Coetzee.
