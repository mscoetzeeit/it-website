LEARN IT

Two parts and one rule

Every recursive method has two parts. The base case is the smallest problem, answered directly with no further call. The recursive case calls the same method with a smaller problem and then uses the answer. The one rule: every call must move closer to the base case, otherwise the calls never stop. Each call gets its own copy of the parameters, and the calls wait in a pile called the call stack: the newest call sits on top and is the first to finish.
Delphi
function SumTo(n: Integer): Integer;
begin
  if n = 0 then
    Result := 0                  // base case: no further call
  else
    Result := n + SumTo(n - 1);  // recursive case: smaller problem
end;
LEARN IT

Down and back up

Code placed before the recursive call runs on the way down, in the order of the calls; code placed after it runs on the way back up, in the reverse order. If the base case is missing, or the call does not get smaller, the calls never stop and the program ends with a stack overflow. A loop uses less memory, but recursion is natural when a problem contains a smaller copy of itself, such as the digits of a number or the letters of a word. Example: Fall(3) writes down 1, down 2, down 3 because the writing happens after the call.
Delphi
procedure Climb(n: Integer);
begin
  if n > 0 then
  begin
    memOut.Lines.Add('up ' + IntToStr(n));    // BEFORE the call
    Climb(n - 1);
  end;
end;                                           // Climb(3): up 3, up 2, up 1

procedure Fall(n: Integer);
begin
  if n > 0 then
  begin
    Fall(n - 1);
    memOut.Lines.Add('down ' + IntToStr(n));  // AFTER the call
  end;
end;                                           // Fall(3): down 1, down 2, down 3

The Question 1 toolkit

Most Question 1 marks come from a handful of patterns. Learn to recognise them.
PatternHow it works
Walk a stringfor i := 1 to Length(s) do and look at s[i]. The first character is at position 1.
Take it apartPos(sub, s) gives the position of the first match, or 0 if there is none. Copy(s, start, count) returns text; Delete(s, start, count) removes it from s itself (a procedure, not a function).
Characters and codesOrd('A') = 65, Chr(66) = 'B'; a lower-case letter is 32 more than its capital. UpperCase and LowerCase change a whole string, UpCase a single character.
Counter and totalSet to 0 before the loop. Inc(iCount) when the condition is true; add to the total on every pass.
Highest or lowestStart the highest at a value no mark can be below (or at the first value) and replace it whenever something larger is found.
Reading until a sentinelRead once before a WHILE loop and read again as the last line inside it, otherwise the loop never ends.
DecisionsTest the most specific rule first in an else-if ladder, put brackets round every comparison joined by and/or, and use case for whole-number ranges such as 80..100.
Safe divisionTest that the counter is more than 0 before dividing by it.

Search, sort and a helper

A linear search uses a flag and stops as soon as the item is found. A sort must swap every parallel array whenever it swaps two items. Binary search only works on a sorted array. The helper function turns seconds into m:ss, adding a leading 0 when the seconds are less than 10.

bFound := False;
i := 1;
while (i <= iCount) and (not bFound) do
  if arrName[i] = sFind then
    bFound := True
  else
    Inc(i);
// bFound False means not found; otherwise i is the position

// bubble sort, smallest time first, names move with the times
for i := 1 to iCount - 1 do
  for j := 1 to iCount - i do
    if arrTime[j] > arrTime[j + 1] then
    begin
      iTemp := arrTime[j];  arrTime[j] := arrTime[j + 1];  arrTime[j + 1] := iTemp;

  iSec: Integer;
begin
  iSec := iTime mod 60;

    Result := Result + '0';
  Result := Result + IntToStr(iSec);
end;

A complete class: TParcel (the interface)

A class has private attributes (fields, prefixed with f) and public methods. Put each class in its own unit (here UParcel) so that other units can only use the public methods; the interface lists the attributes and the headings of the methods.

  TParcel = class
  private
    fID      : string;

    fInsured : Boolean;

  public

LEARN IT

TParcel: constructor, accessor and mutator

The constructor sets the starting values (here insured starts False without being a parameter). An accessor (Get) returns an attribute. A mutator (Set) changes one and can protect it with a rule.
Delphi
implementation
constructor TParcel.Create(sID: string; rWeight: Real; iZone: Integer);
begin
  fID := sID;
  fWeight := rWeight;
  fZone := iZone;
  fInsured := False;               // a default, not a parameter
end;
procedure TParcel.SetZone(iNew: Integer);
begin
  if (iNew >= 1) and (iNew <= 3) then

end;
LEARN IT

TParcel: auxiliary method, CalcCost and ToString

An auxiliary method is a private helper that a public method calls; it returns a result and never changes an attribute. CalcCost works from attributes without storing the answer. ToString returns the object's state as text. In the form, create the object with objP := TParcel.Create('PX7', 3.5, 2); and call the methods on the object variable, for example objP.SetInsured(True) or memOut.Lines.Add(objP.ToString); with PX7 insured, ToString ends in R88.75.
Delphi
function TParcel.BaseRate : Real;
begin
  case fZone of
    1: Result := 35;
    2: Result := 55;
  else
    Result := 80;
  end;
end;

function TParcel.CalcCost : Real;
begin
  Result := BaseRate;                          // the auxiliary method gives the zone rate
  if fWeight > 2 then
    Result := Result + (fWeight - 2) * 12.5;   // R12.50 for every kg over 2
  if fInsured then
    Result := Result + 15;
end;

function TParcel.ToString : string;

The order the database thinks in

A query is not worked out in the order it is written. The database works in this order: FROM (which tables), WHERE (keep or drop single records, including the join condition), GROUP BY (collect the records into groups), HAVING (keep or drop whole groups), SELECT (work out the columns and the aggregates) and ORDER BY (sort). That is why an aggregate such as SUM can never be in WHERE (the groups do not exist yet) and why every field in SELECT that is not inside an aggregate must also be in GROUP BY. Use the join condition in WHERE whenever two tables are listed in FROM. AND is worked out before OR, so use brackets. Dates are written #yyyy/mm/dd#, and to cover a whole month ask for >= the first day and < the first day of the next month. Text values go in double quotes, & joins pieces of text, TOP n follows SELECT, and for LIKE use the wildcard character that the question's database uses (% or *). In Access you cannot use an alias you created with AS inside WHERE or HAVING: repeat the calculation.
SQL
SELECT B.BranchName, SUM(O.Qty * O.UnitPrice) AS Revenue
FROM tblBranch B, tblOrder O
WHERE B.BranchID = O.BranchID
AND O.OrderDate >= #2026/09/01#
GROUP BY B.BranchName
HAVING SUM(O.Qty * O.UnitPrice) > 500
ORDER BY Revenue DESC;

Search, the web and online applications

A keyword search matches the words typed. A semantic search works out the meaning and intention behind the words, using context such as earlier searches and location. Networks, connections and sharing

A switch joins the devices of one LAN and sends data only to the device it is meant for. A router joins different networks, such as the school LAN and the Internet, and chooses the best route. A wireless access point (the base station for Wi-Fi) lets wireless devices join the wired network. UTP cable is cheap and works up to about 100 m; fibre carries light, is faster, goes much further and is hard to tap, but costs more.

Shared folders carry user rights (no access, read-only, read/write, full control). Give each person the lowest right that lets them do their job, so a mistake or virus on one account cannot damage everything. BitTorrent is peer-to-peer sharing: a file is cut into pieces that are downloaded from many peers at once while you upload pieces to others. It spreads large legal files cheaply, but it is often used for piracy and your IP address is visible to the other peers. Remote access means using a computer or network from another place: over a LAN, over the Internet, or through a VPN, which adds an encrypted tunnel across the public Internet so that someone at home or in a coffee shop can use the company network safely.

LEARN IT

Keeping data safe

SSL/TLS secures the connection between a browser and a web server (HTTPS and a padlock). The server has a public key that anyone may have and a private key that only it keeps; data locked with the public key can only be unlocked with the private key. A digital certificate, signed by a trusted certificate authority, proves that the site really belongs to the organisation. A firewall filters traffic into and out of a network by rules.

Grade 11 review. Symmetric encryption uses one shared key, asymmetric encryption uses a pair of keys. A blockchain is a chain of blocks of records, each storing a fingerprint (hash) of the block before, copied over many computers, so changing an old record breaks the chain and is noticed. MFA needs two or more different kinds of proof (something you know, have or are), so a stolen password alone is not enough.

LEARN IT

Computers, society and privacy

Distributed computing splits one huge problem, such as forecasting the weather for the whole country, into small pieces that many computers solve at the same time before the answers are combined: it gives the power of a supercomputer without owning one. Social networking helps people connect, communities organise and small businesses advertise cheaply, but it also brings cyberbullying, false information, time wasted and loss of privacy. Cookies record the sites you visit so that advertisers can follow you. A GUID is a globally unique identifier that lets a site or app recognise your device everywhere. Anonymity lets people speak freely but also lets them hide while they bully or commit crime. POPIA says that organisations may collect personal information only with a reason and consent, must keep it secure and must report breaches.
