LEARN IT

What is a loop?

A loop repeats a set of instructions. Before you write any loop, answer three questions:
  1. What must be repeated?
  2. How many times, or until when?
  3. What changes each time round?
Delphi has three loops. The FOR loop is used when you know how many times to repeat.
LEARN IT

The FOR loop

iCount is the counter. It starts at 1 and Delphi adds 1 to it every time round, all by itself, until it passes 5. Everything between begin and end is the loop body. To count backwards write downto instead of to. You do not need begin…end if the body is only one statement.
Delphi
var
  iCount, iTotal : Integer;
begin
  iTotal := 0;
  for iCount := 1 to 5 do
  begin
    iTotal := iTotal + iCount;
  end;
  ShowMessage(IntToStr(iTotal));   // shows 15
end;

1.4Fill in the blanks [4]

LEARN IT

WHILE and REPEAT

WHILE checks its condition first. It keeps going while the condition is True, so it may run zero times. REPEAT…UNTIL checks last. It keeps going until the condition becomes True, so it always runs at least once. A special value that tells the loop to stop (like 0 or -1) is called a sentinel. Inside the loop you must change something, otherwise the condition never changes and the loop never ends.
Delphi
// WHILE: test first. Sentinel = 0
iNum := StrToInt(InputBox('Input', 'Number (0 to stop):', ''));
while iNum <> 0 do
begin
  iTotal := iTotal + iNum;
  iNum := StrToInt(InputBox('Input', 'Number (0 to stop):', ''));
end;

// REPEAT: test last. Keeps asking until the age is valid
repeat
  iAge := StrToInt(InputBox('Age', 'Enter your age (14 to 19):', ''));
until (iAge >= 14) and (iAge <= 19);

LEARN IT

Strings, positions and a loop

In Delphi the first character is at position 1 (not 0). Length(s) tells you how many characters there are, and s[i] gives the character at position i. A FOR loop from 1 to Length(s) visits every character. You can build a new string by adding characters to it with +.
Delphi
sWord := 'LOGIC';
for i := 1 to Length(sWord) do
  memOut.Lines.Add(IntToStr(i) + ': ' + sWord[i]);
// 1: L   2: O   3: G   4: I   5: C
LEARN IT

Ord and Chr

Every character has a number (its ASCII code). Ord(c) gives the number for a character and Chr(n) gives the character for a number. The letters of the alphabet are in order, so Chr(Ord('A') + 1) is 'B'. A lowercase letter is 32 more than its uppercase letter.
Delphi
iCode := Ord('A');         // 65
cNext := Chr(iCode + 1);   // 'B'
cLower := Chr(Ord('A') + 32);   // 'a'

4.3GCD and LCM by hand [4]

LEARN IT

Teaching the computer

x is a factor of n when n MOD x = 0 (no remainder). To test for a prime, count the factors by trying every number from 1 to n. A number is prime if it is greater than 1 and has exactly 2 factors.
Delphi
iCount := 0;
for iDivisor := 1 to iNumber do
  if iNumber mod iDivisor = 0 then
    Inc(iCount);
bPrime := (iNumber > 1) and (iCount = 2);
LEARN IT

The remainder method for GCD

To find the GCD of two numbers, keep replacing the pair with (second number, remainder) until the remainder is 0. The last non-zero number is the GCD. Then LCM = (first DIV GCD) × second.
Delphi
iA := 48;
iB := 18;
while iB <> 0 do
begin
  iRemainder := iA mod iB;
  iA := iB;
  iB := iRemainder;
end;
// iA now holds the GCD
